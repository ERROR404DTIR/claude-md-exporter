Install in three steps

  1. Show your bookmarks toolbar. In most desktop browsers, press Ctrl + Shift + B.
  2. Drag the green “Claude Export” link above onto that toolbar. Or copy it and paste into a new bookmark's URL field.
  3. Open a Claude conversation while signed in, then click your new bookmark. The Markdown file will download.

🔐 Your chat stays yours

The bookmarklet makes a same-origin request to Claude's own conversation endpoint using the session already open in your browser. It does not transmit chat contents to this project or analytics services.

Know what you install

Bookmarklets run with the permissions of the page they are opened on. Review the source before installing. This project does not fetch remote code when you click the bookmark.
